# PDF to Word — Quick Test Checklist

1. **Normal text PDF:** 2–3 pages with selectable text. Confirm OCR pages = 0 and output opens in Word.
2. **Scanned image PDF:** scan 2 pages to images and create PDF. Keep automatic OCR ON. Confirm both scanned pages are listed under OCR pages and their text appears in DOCX.
3. **Mixed PDF:** page 1 text PDF, page 2 scan, page 3 text PDF. Confirm only page 2 is OCR processed.
4. **Hindi PDF:** select Hindi or English + Hindi and check matras/characters in Word.
5. **Tables:** invoice or statement with at least 3 rows. Verify reconstructed cells and totals manually.
6. **Force OCR:** enable Force OCR on every page for a PDF with selectable text; compare output.
7. **Limits:** test a file over 60 MB and a PDF over 80 pages; the tool should show a clear message rather than crash.
8. **Password-protected PDF:** confirm the error is clear; unlock it first with the password if authorized.

OCR spelling, small print, skewed pages, handwriting and complex tables can still be inaccurate. Compare important numbers and names with the original PDF before using the Word file.
