CONVIA CENTRAL ADSENSE MANAGER — START HERE

Aap Hostinger Business plan par Node.js/Next.js app ko GitHub se deploy karte hain. Is package ka design:
- Hostinger MySQL database me ad-unit settings save karta hai.
- Admin page: /admin/ads
- Har ad code ke liye alag entry; one snippet at a time.
- Code paste karne par <ins class="adsbygoogle"> se safe IDs/format/layout read karta hai. Pasted <script> code execute/store nahi karta.
- Ad placements: after-header, before-footer, left/right desktop rail, optional homepage-after-hero, optional pdf-after-tool.
- Scope: all public pages, homepage, PDF pages, exact route.
- Device: all, desktop, mobile.
- Enable/disable/delete controls.
- Ad settings save karne ke baad naya ad add karne ke liye GitHub push nahi chahiye.

INSTALL SUMMARY
1) PATCH folder ko D:\convia me merge karein.
2) Root terminal: npm install mysql2
3) Hostinger hPanel me MySQL DB/user banayein.
4) Hostinger Node.js app Environment Variables me DB_HOST=127.0.0.1, DB_PORT=3306, DB_USER, DB_PASSWORD, DB_NAME add karein.
5) Adult AdSense account owner ke control me CONVIA_ADS_ADMIN_PASSWORD aur CONVIA_ADS_SESSION_SECRET set karein.
6) Existing app/layout.tsx me layout-ad-manager-snippet.tsx.txt ka snippet merge karein; existing ThemeProvider/Navbar/Footer aur ek global AdSense script preserve karein.
7) Homepage/PDF page specific placements chahiye to optional AdZone add karein.
8) npm run build, git add -A, git commit, git push origin main.
9) Hostinger redeploy. /admin/ads open karein.

SAFETY / ACCOUNT OWNERSHIP
AdSense account and payment profile must belong to and be administered by an adult account holder. The adult account owner should set and manage the dashboard password. Do not share Google account passwords or payment credentials.

IMPORTANT
Google does not guarantee every ad unit will fill on every route/page view. Anchor/Vignette Auto Ads are controlled through AdSense dashboard, not pasted as manual ad units here. Do not use excessive ads, forced popups/popunders, auto-refresh, or ads adjacent to PDF action buttons.
